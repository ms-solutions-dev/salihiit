# Coach voices

The countdown recordings in `App/Resources/Stimmen/` and `Watch/Resources/Stimmen/` were generated
with [ElevenLabs](https://elevenlabs.io) on a paid (Creator) plan, which grants commercial use of
the output. One male and one female voice per language:

| Folder | Name | Language |
|---|---|---|
| `ben` | Ben | German |
| `laura-de` | Laura | German |
| `hasan` | Hasan | Turkish |
| `elif` | Elif | Turkish |
| `charlie` | Charlie | English |
| `laura` | Laura | English |

projects. Generate your own voices for anything else.
